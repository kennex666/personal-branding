## 🧠 Overview

**Doome App Logo** is an original digital artwork created by **Duong Thai Bao** as the primary app icon and brand identifier for **Doome Chat** (an anonymous messaging application featuring masked identity protocols).

The logo encapsulates the privacy-first, secure, and masked identity themes of the application in a concise graphical format.

This specific repository/folder acts as the canonical collection of the app logo's versions, documenting its design evolution for multi-platform UI/UX implementation:
- **[doome-v1.png](./doome-v1.png)**: The first iteration of the application logo, representing the initial visual identity.
- **[doome-v2.png](./doome-v2.png)**: The second and refined iteration of the application logo, optimized for modern digital platforms.
