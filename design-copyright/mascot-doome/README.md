## 🧠 Overview

**Doome Identity Mascot (Expression Set)** is an original digital artwork created by **Duong Thai Bao** as the core visual ambassador for the **Doome Chat** (an anonymous messaging application featuring masked identity protocols).

The mascot features a stylized handcrafted character design characterized by a distinctive chat-bubble shaped head, spectacles formed by two structural "O" characters, and a central connecting upward arc. 

This specific repository/folder acts as the canonical collection of the mascot's behavioral states, optimized for multi-platform UI/UX implementation:
- **[doome-normal.png](./doome-normal.png)**: The primary emblem featuring a neutral/steady gaze, used for standard interface navigation and general brand assets.
- **[doome-happy.png](./doome-happy.png)**: An elevated variant displaying animated joy, utilized for system success events, matching confirmations, and reward states.
- **[doome-attention.png](./doome-attention.png)**: A focused/alert variant designed for real-time notifications, system empty states, and system error indicators.
